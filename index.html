Network Traffic Classification Matrix

Threshold Rules & Network Impact
GREEN

LOW TRAFFIC

0 Mbps - 350 Mbps (0% - 35%)

Network State: Normal operating conditions. Bandwidth availability is high and packet queues are empty.

  • Latency: Low (< 20 ms)
  • Packet Drops: 0%
  • System Action: No intervention required. System running smoothly.
YELLOW

MEDIUM TRAFFIC

351 Mbps - 700 Mbps (36% - 70%)

Network State: Moderate congestion. Routers experience packet buffering and queue depths increase.

  • Latency: Moderate (20 - 60 ms)
  • Packet Drops: Minimal (< 0.5%)
  • System Action: Monitor bandwidth usage; prepare queue optimization.
RED

HIGH TRAFFIC

701 Mbps - 1000 Mbps (71% - 100%)

Network State: Critical overload / potential DDoS attack. Buffer overflow causes packet drops and high jitter.

  • Latency: Severe (> 100 ms)
  • Packet Drops: High (> 2.0%)
  • System Action: Trigger rate-limiting, load balancing, or admin alert.

Project Title

Virtual Lab Network Traffic Light (Product No. 33)

Problem Statement

Traditional computer network laboratory experiments often rely on expensive physical hardware (microcontrollers like Arduino/Raspberry Pi, breadboards, physical LEDs, or dedicated router testbeds). These setups suffer from hardware availability constraints, maintenance costs, and wiring complexities. Students need a 100% software-based, interactive virtual lab environment to learn network traffic dynamics, threshold monitoring, and visual status signaling without physical hardware.

Objective

  • Simulate real-time computer network traffic bandwidth variations (0 to 1000 Mbps).
  • Map continuous numerical traffic values into discrete operational states: LOW (Green), MEDIUM (Yellow), and HIGH (Red).
  • Provide an intuitive virtual traffic light visual indicator with animated illumination effects.
  • Render live traffic trend charts and maintain historical logs for bandwidth analysis.
  • Offer an easy-to-understand codebase for 2nd-year BTech CSE student presentation and demonstration.

How the System Works

  1. Data Generation / Ingestion: When the user clicks "Simulate Traffic" or enables "Auto Simulation", the system generates a traffic value between 0 and 1000 Mbps (or loads preset scenarios).
  2. Threshold Classification Logic:
    • 0 - 350 Mbps (≤ 35%) → Classified as LOW → Activates GREEN Light
    • 351 - 700 Mbps (36% - 70%) → Classified as MEDIUM → Activates YELLOW Light
    • 701 - 1000 Mbps (> 70%) → Classified as HIGH → Activates RED Light
  3. UI & DOM Synchronization: The virtual traffic light casing updates its active glowing lamp, updates status badges, latency/packet loss metrics, and timestamp.
  4. Graph & History Updates: The new data point is pushed to the Chart.js dataset and appended to the dynamic history log table.

Technologies Used

  • HTML5 Semantic Page Layout
  • CSS3 Glassmorphism, CSS Variables, Animations
  • JavaScript (ES6+) DOM Manipulation, Event Listeners, State Management
  • Chart.js HTML5 Canvas Data Visualization
  • Font Awesome Vector Iconography

Future Scope

  • Real Packet Sniffing: Integrate with WebSockets or backend APIs (e.g., Python Scapy / Wireshark) for live network packet monitoring.
  • Machine Learning Anomaly Detection: Implement predictive models to detect DDoS attacks before thresholds are crossed.
  • Multi-Node Topology: Extend the single traffic light into a virtual network topology visualizer with multiple router nodes.
  • Automated Email Alerts: Send SMTP alerts to network administrators when the light turns RED.
